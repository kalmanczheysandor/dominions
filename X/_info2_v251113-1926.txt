	DNS.3 = admin.dominions.hu

	Megoldas:
	
	
	A Chrome / Edge / Firefox ilyenkor azt mondja:
		“A kapcsolat nem biztonságos — a tanúsítványt nem egy megbízható hitelesítő adta ki.”
		Mivel fejlesztői környezetben vagy, ez nem funkcionális hiba.
		A böngésző szándékosan blokkolja a kérést JavaScript szinten, ha a fetch() vagy axios HTTPS hívása invalid certet talál.

		A megoldás, attól függően, mit szeretnél:
		🥇 Fejlesztéshez (ajánlott):

		Telepítsd a tanúsítványt Windows alá, mint megbízható hitelesítőt.

		Keresd meg a fájlodat:
		👉 C:\_services\apache\conf\ssl\dominions.hu.crt

		Duplán kattintsd meg.

		Válaszd:

		„Telepítés a helyi gépre” (Local Machine)

		Cél tároló: „Megbízható gyökértanúsítvány-kibocsátók” (Trusted Root Certification Authorities)

		Nyomj végig „Tovább” és „Befejezés”.

		Indítsd újra a böngészőt (Chrome/Edge/Firefox).

		Ezután a https://api.dominions.hu már zöld lakatos lesz, és a fetch működni fog.

		✅ Ezzel a hiba teljesen eltűnik.

<<< 2 - Apache szerkesztese >>>>>>

1) Ezek a modulok legyenek aktivak
	LoadModule ssl_module modules/mod_ssl.so
	LoadModule socache_shmcb_module modules/mod_socache_shmcb.so
	LoadModule headers_module modules/mod_headers.so				(arra kel, hogy a vhost confban mukodjon a "RequestHeader" resz)												
	
2) Ha még nincs Include sor az extra vhosts file-ra, tedd hozzá.

3) A figyelesi portokat is allitsd be:

3/b) Meg kell vizsgalni admin modban, hogy az apache figyel-e a 443-as porton
netstat -ano | find ":443"



4) a virtual hostok
	!!!!! Arra vigyazz, hogy a backend microservicei http-ben es nem https-ben futnak.


	<VirtualHost *:443>
		ServerName dominions.hu
		DocumentRoot "C:/@/@Szakdolgozat1/_apps/Dominions/DominionsSiteFrontend/dist"

		<Directory "C:/@/@Szakdolgozat1/_apps/Dominions/DominionsSiteFrontend/dist">
			AllowOverride All
			Require all granted
		</Directory>

		SSLEngine on
		SSLCertificateFile "C:/_services/apache/conf/ssl/dominions.hu.crt"
		SSLCertificateKeyFile "C:/_services/apache/conf/ssl/dominions.hu.key"

		ProxyPreserveHost On
		ProxyPass /api https://api.dominions.hu/
		ProxyPassReverse /api https://api.dominions.hu/
	</VirtualHost>

	<VirtualHost *:443>
		ServerName admin.dominions.hu
		DocumentRoot "C:/@/@Szakdolgozat1/_apps/Dominions/DominionsAdminFrontend/dist"

		<Directory "C:/@/@Szakdolgozat1/_apps/Dominions/DominionsAdminFrontend/dist">
			AllowOverride All
			Require all granted
		</Directory>

		SSLEngine on
		SSLCertificateFile "C:/_services/apache/conf/ssl/dominions.hu.crt"
		SSLCertificateKeyFile "C:/_services/apache/conf/ssl/dominions.hu.key"

		ProxyPreserveHost On
		ProxyPass /api https://api.dominions.hu/
		ProxyPassReverse /api https://api.dominions.hu/
	</VirtualHost>

	<VirtualHost *:443>
		ServerName api.dominions.hu

		SSLEngine on
		SSLCertificateFile "C:/_services/apache/conf/ssl/dominions.hu.crt"
		SSLCertificateKeyFile "C:/_services/apache/conf/ssl/dominions.hu.key"

		ProxyPreserveHost On
		ProxyPass / http://localhost:15000/
		ProxyPassReverse / http://localhost:15000/
	</VirtualHost>

	Megjegyzes:
		Miért fontos a <Directory> blokk
		Beállítás	Miért kell
		AllowOverride All	--- Engedélyezi, hogy a Vue build könyvtárban lévő .htaccess fájl újraírásokat, fallbacket használjon (pl. history mode).
		Require all granted	--- Biztosítja, hogy az Apache tényleg kiszolgálhassa a dist mappát (különben 403 hiba jöhet).

		Tehát mindkét frontend VirtualHosthoz kötelező.
		A backend (api.dominions.hu) nem szolgál statikus fájlokat, csak proxizál, ezért oda nem kell <Directory> blokk.

7) a site es admin frontend ala pedig kell htaccess file

<IfModule mod_rewrite.c>
  RewriteEngine On
  RewriteBase /

  # Ha a kérés egy létező fájlra mutat, ne módosíts semmit
  RewriteCond %{REQUEST_FILENAME} -f [OR]
  RewriteCond %{REQUEST_FILENAME} -d
  RewriteRule ^ - [L]

  # Egyébként irányítsd át az index.html-re (Vue router kezeli)
  RewriteRule ^ index.html [L]
</IfModule>

# Biztonsági fejlécek (opcionális, de hasznos)
<IfModule mod_headers.c>
  Header set Cache-Control "no-cache, no-store, must-revalidate"
  Header set Pragma "no-cache"
  Header set Expires 0
</IfModule>
